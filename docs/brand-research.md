# 29 品牌公开资料核查

整理日期：2026-10-16。29 个原始入口均返回 HTTP 200，并通过未登录页面标题或公开品牌配置核对名称。页面多为跳转、登录或验证入口，未注册、登录、付款，未验证套餐到账或优惠码。

表内价格均为第三方资料参考，非当前结算报价。极连云旧资料存在同名关联疑点，未收录报价。各页保留来源冲突和购买前重点核对项。没有引用他人的测速作为本站实测。

推荐依据：暮光网络适合先建立月度流量基线的人。参考资料中，20 元对应 120GB，40 元对应 240GB，两档价格和容量同步翻倍；先从较小档记录自己的消耗，比一开始购买用不完的大包更容易控制支出。

资料局限：40 元档有其他页面写成 300GB；本页采用较保守的 240GB 参考值，不据此承诺实际到账额度。

来源：https://tizilab.cc/paihang/twilight/
