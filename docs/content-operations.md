# 内容与品牌维护

- `src/data/airports.ts` 维护 29 个品牌的推荐依据、参考套餐、来源冲突和核查项。不得未经授权改变品牌范围或顺序。
- `src/data/brand-editorial.ts` 维护 29 份专属定位、人群与选择分析；`src/data/selection.ts` 维护六个场景及其预算 / 容量条件。不要把按容量筛出的名单改写为已验证的专线、AI、流媒体或稳定性推荐。
- 引用的未知协议、设备、倍率与性能保留缺口。对比工具的档位切换、预算计算与筛选只使用明确的输入，不把未知报价当作零价，不把未知倍率设为 1。
- `src/data/brand-manifest.json` 是用户指定名称、顺序、原始推广链接及 11 个优惠码的校验基准。不要规范化或补造链接中的参数。
- 套餐价格来自第三方资料，`verified:false`。只有当前结算、流量、周期、倍率均有证据时才可改为已核实；缺失倍率不能默认 1。
- 页面查询日期不是原始价格生效日期，不等于到账确认或测速日期。来源冲突需公开，不能拼接不同版本的低价与大容量。
- 不补入其他品牌、网上找到的其他优惠码或未经验证的折扣。指定码的有效期与适用条件在结账时另行确认。
- `tested` 状态需要真实原始测试记录。本期不包含速度、稳定性、AI 或流媒体实测，不生成推测分数。
- 顺序由站长安排，存在直接商业推广关系；可见披露和 `sponsored nofollow noopener noreferrer` 必须保留。
- Markdown 保留明确来源与真实日期；教程不保证任意品牌都支持通用订阅。源码、搜索、站点地图及交付包均不应残留旧品牌。
- 修改后运行 `npm run qa`；涉及界面时验证手机端和浏览器。检查程序不代替对资料真实性及服务归属的核实。

尚待补充：当前结算页、优惠条件、线路与设备限制、实际网络记录。极连云历史 hyperlink 服务与当前入口的关联也需要确认，参见 `brand-research.md`。

## 博客文章维护

- 当前博客150篇，按十类组织。文章保留 `category`、唯一 `order`、独立标题/摘要、原始发布日期和实质更新日期；不要为重新构建刷新日期。
- `src/data/blog.ts` 维护主题顺序、交错主目录与15篇分页。每个专题有静态页面，正文来自Markdown；关键词筛选不能替代静态内链。
- 构建先自动同步 `article-index.json` 与 `docs/blog-catalog.csv`，再生成所有HTML。修改内容后执行构建，目录与全站搜索无需手工复制。
- 同一问题应优先改写原文而非继续添加近义标题。每篇说明一个明确的操作或判断意图，事实引用紧邻正文，假设数字显式标注示例。
- 报价来源不等于当前结算确认；平台规则与软件文档只适用于对应产品，不延伸成所有品牌的保障。OpenAI网页与API、设备授权与商业套餐资格也须区分。
- `npm run qa` 包含博客结构/重复度检查；`npm run qa:blog` 检查筛选、分页、刷新恢复、无JS150篇可达及多宽度布局。自动检查不能替代事实阅读。
- 选题和来源对应表见四份 `docs/blog-research-*.md`，编辑复核范围见 `docs/blog-editorial-review.md`。

## 主词页面维护

- 首页主攻“机场推荐”；Title、Description、H1由`src/data/seo.ts`集中维护。修改后同步首屏内容和搜索意图映射。
- `/recommend/`承接按预算、设备与场景筛选；`/ranking/overall/`是站长目录；`/blog/choose-a-service/`解释怎么选。页面标题相同词数量不是排名指标，不把独立长尾文章全部改写为首页主题。
- 主导航“机场推荐”指向根地址。选购相关正文的返回入口应帮助读者继续选择，技术排障文章不机械插入同一段关键词。
- 首页目录Schema只反映实际品牌及指定顺序，不新增无证据评分。未核实价格、折扣和性能保持原有边界。
- 站内布局、GitHub同步、正式站抓取、Bing收录和查询表现是不同状态，必须按证据分别记录。
